# Subtra P3 Implementation Plan

> **For agentic workers:** Execute inline, task by task, with TDD. Steps use checkbox syntax.

**Goal:** Ship the P3 feature set: terminology glossary, embedded-subtitle import, CI, packaging metadata, app icon, docs — version 2.4.0.

**Architecture:** Each feature is a small, dependency-free module wired into the existing `JobSettings` → `JobRunner` pipeline and the existing PySide6 tabs. Network/model-dependent paths stay behind the established SKIP contract.

**Tech Stack:** Python 3.13/3.14, PySide6, faster-whisper, CTranslate2 (NLLB), FFmpeg/ffprobe, GitHub Actions.

**Spec:** user objective "P3" + P2 backlog recorded in the project README/checkpoint.

## Global Constraints

- UI text stays Turkish; README English primary, `docs/README.tr.md` secondary.
- No new runtime dependency (stdlib only for glossary; FFmpeg via subprocess, never `shell=True`).
- Tests never download models: `SUBTRA_NO_DOWNLOAD=1`, missing model → SKIP (exit 77).
- No media, `.srt`, `.bin`, model files or keys committed; source only.
- Version single-source in `version.py`; `main` gets only tagged releases.
- Source files LF, `.bat`/`.ps1` CRLF (`.gitattributes`).

## Review Focus

- Glossary term with regex metacharacters (`C++`, `(beta)`) must be literal.
- Turkish dotted/dotless i (`İ`, `ı`) must match case-insensitively without changing offsets.
- Placeholder lost by NLLB must degrade to direct replacement, never leak `[[G0]]` into subtitles.
- Embedded image-based subtitles (PGS/VobSub) must fail with a clear message, not an empty SRT.
- CI must pass on a clean clone without models, ffmpeg or a checked-out tag.

### Task 1: Glossary module + tests

**Files:** Create `glossary.py`, `test/test_glossary.py`.

**Interfaces:**
- `GlossaryError(ValueError)`
- `GlossaryEntry(source: str, target: str, pair: str = "")`
- `load_glossary(path: str | Path) -> Glossary`
- `Glossary.entries`, `__len__`, `__bool__`
- `Glossary.entries_for(source_lang: str, target_lang: str) -> tuple[GlossaryEntry, ...]`
- `Glossary.protect(text: str, source_lang: str, target_lang: str) -> tuple[str, dict[str, str]]`
- `Glossary.restore(text: str, mapping: dict[str, str], source_lang: str, target_lang: str) -> tuple[str, int]`
- `Glossary.apply(text: str, source_lang: str, target_lang: str) -> str` (single-string convenience for post-edit/fallback use)

Semantics: TSV (tab) or ` -> ` arrow; `#` comments; optional 3rd column `en>tr`; header lines skipped; longest term wins; literal matching with word boundaries only when the term edge is alphanumeric; case-insensitive via length-preserving fold (Turkish-aware); placeholders `[[G<i>]]` verified by NLLB to survive translation.

### Task 2: Glossary in the translation pipeline

**Files:** Modify `translator.py`, `worker.py`, `gui.py` (Settings), `test/test_glossary_flow.py`, `test/test_glossary_pipeline.py`.

**Interfaces:** `translate_sentences(..., glossary=None, source_lang="", target_lang="")`; `TranslationPipeline(..., glossary=None, source_lang="", target_lang="")`; `JobSettings.glossary_path: str = ""`.

Worker logs applied count, warns on lost placeholders, fails fast with a clear message if the file is unreadable.

### Task 3: Embedded subtitle import

**Files:** Modify `ffmpeg_utils.py`, `gui.py`; create `test/test_subtitle_import.py`.

**Interfaces:** `subtitle_streams(ffprobe, path) -> list[dict]` (`index`, `language`, `title`, `codec`, `default`, `forced`, `text_based`); `extract_subtitle_stream(ffmpeg, path, stream_index, out_srt, cancel_event=None) -> Path`.

GUI: "Gömülü Altyazı Kullan…" button in Video tab → stream picker → extract → SRT tab prefilled.

### Task 4: pyproject + CI + version-tag test fix

### Task 5: App icon

### Task 6: Docs, version 2.4.0, release

**Files:** `version.py`, `README.md`, `docs/README.tr.md`, `docs/GLOSSARY.md`; tag `v2.4.0`; merge to `main`; push.
